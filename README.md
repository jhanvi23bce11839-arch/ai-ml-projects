# AI & Machine Learning Projects

This repository contains a collection of Artificial Intelligence and Machine Learning projects completed as part of coursework and practical assignments. The projects cover supervised learning, deep learning, reinforcement learning, recommendation systems, deployment, and Retrieval-Augmented Generation (RAG).

---

## Projects

### 1. Adult Census Income Classification
- Predicts whether a person's income exceeds a specified threshold.
- Algorithms: Machine Learning Classification
- Dataset: Adult Census Income Dataset

---

### 2. CIFAR-10 Image Classification using CNN
- Image classification using a Convolutional Neural Network.
- Dataset: CIFAR-10

---

### 3. Face Recognition using CNN (LFW Dataset)
- Face recognition using the Labeled Faces in the Wild (LFW) dataset.
- Uses Convolutional Neural Networks for classification.

---

### 4. Cancer Detection using MRI Images
- Brain tumor detection using MRI images.
- Image preprocessing and deep learning techniques were used for classification.

---

### 5. CartPole Reinforcement Learning Agent
- Reinforcement Learning agent trained on the CartPole environment.
- Demonstrates agent learning using rewards.

---

### 6. Movie Recommendation System
- Content-based movie recommendation system.
- Uses cosine similarity and feature extraction to recommend similar movies.

---

### 7. End-to-End Render Deployment Project
- Machine Learning model deployed using Flask and Render.
- Demonstrates model deployment and web application development.

---

### 8. RAG Chatbot (Capstone Project)
- Retrieval-Augmented Generation (RAG) implementation using LangChain, Hugging Face Embeddings, and FAISS.
- Retrieves relevant information from PDF documents using semantic search.
